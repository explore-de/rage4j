## Project Overview

This is the Docusaurus documentation site for Rage4J, a RAG Evaluation library for Java. The site is deployed to GitHub Pages at https://explore-de.github.io/rage4j/.

## Build Commands

```bash
# Install dependencies
npm install

# Start local development server (hot reload)
npm start

# Build static site
npm run build

# TypeScript type checking
npm run typecheck

# Serve production build locally
npm run serve
```

## Docker Development

```bash
# Development (hot reload on port 3000)
docker build --target development -t rage4j-docs:dev .
docker run -p 3000:3000 rage4j-docs:dev

# Production build with Nginx (port 80)
docker build --target deploy -t rage4j-docs:deploy .
docker run -p 80:80 rage4j-docs:deploy

# Docker Compose (port 3005)
docker-compose up
```

## Project Structure

- `docs/` - Markdown documentation content (auto-generates sidebar via `sidebars.ts`)
- `src/pages/` - Custom React pages (homepage at `index.tsx`)
- `src/components/` - React components
  - `HomepageFeatures/` - Main landing page feature sections with scroll animations
  - `ThemeToggleHandler.tsx` - Custom animated theme switching
- `src/api/GitHubApi.ts` - Fetches GitHub stats (stars, forks, version) with cookie caching
- `src/css/custom.css` - Global CSS customizations
- `docusaurus.config.ts` - Site configuration, navbar, footer, SEO metadata

## Architecture Notes

- **Auto-generated sidebar**: Uses `{type: 'autogenerated', dirName: '.'}` - add docs to `docs/` and they appear automatically
- **GitHub stats caching**: Stats are fetched from GitHub API and cached in cookies for 6 hours to avoid rate limits
- **Theme animation**: Custom overlay animation for theme switching on desktop (disabled on mobile)
- **Dynamic Maven versions**: Homepage displays latest release version from GitHub API
